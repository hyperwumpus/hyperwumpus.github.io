SCOUTER / Glitch

Audit, pitch, fix: investigate a business's public presence, record evidence, and organize a proposed improvement.

Run the working app locally

The scanner needs its Node backend. GitHub Pages cannot run live scans. On the Mac, use the supplied launcher or run these commands in the repository:

cd scouter-glitch
npm ci
npm start

Open http://127.0.0.1:4319. Live Business scans require your Google Places key and internet access.

What works today

Business discovery, evidence-based website observations, private lead files, attachments, scoped proposal drafts and Creator reviews of supplied materials. Public YouTube metadata requires a separate key.

How it connects to LeadFlow

SCOUTER helps identify a problem. LeadFlow can be one possible solution for missed inquiries or follow-up. They are separate apps today; there is no automatic integration.
